# Welcome to RAG Application

A Retrieval-Augmented Generation (RAG) application that enables users to upload documents and ask questions about their content. The application retrieves relevant information from the uploaded document, augments the prompt with the retrieved context and generates accurate, context-aware responses using a Large Language Model (LLM).

---

## Features

- Single Responsibility Principle
- Gradio User Interface
- Fast semantic retrieval using FAISS
- FastAPI Backend with clear endpoint seperation

## Installation Guide

### 1. Clone the repository

```powershell
git clone <repository-url>
cd <repository-name>
```

### 2. Create a virtual environment

```powershell
python -m venv venv
```

Activate it:

**Windows**

```powershell
venv\Scripts\activate.ps1
```

### 3. Install dependencies

```powershell

pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file and add your API key.

``` "env.example"

GROQ_API_KEY=your_api_key
```

### 5. Start the FastAPI server

```powershell

uvicorn backend.app:app --reload
```

### 6. Launch the Gradio interface

```powershell
python -m frontend.ui
```

Open the Gradio URL displayed in the terminal.

## Usage

1. Launch the FastAPI backend.
2. Start the Gradio interface.
3. Upload a PDF, DOCX, or TXT document.
4. Wait for the document to be processed.
5. Ask questions related to the uploaded document.
6. Receive context-aware responses generated by the LLM.

---

## Limitations

- Only one document can be processed at a time.
- Uploaded documents are not permanently stored.
- Response quality depends on the retrieved document context.
- Scanned PDFs without OCR are not supported.
- Large documents may require longer processing time.
- Very large documents may consume significant memory during embedding generation.
- The application requires an active internet connection if the LLM API is cloud-hosted.
- The knowledge base is limited to the uploaded document and the LLM's pretrained knowledge.
